# EUCLEA 大学数学

答えを見せるのではなく、自力で方針を立てて解ける頭をつくる大学数学の演習アプリ（試作版 v0.3）。
大学数学（学部〜院試）と、数学検定1級・統計検定（2級・準1級・1級）の演習を扱います。

エンジンは [Lemma 受験数学](https://github.com/kurowasan3/lemma) v0.27 と同じです（今日の学習・解法カードと習熟の判定・推薦・解答の形式の切り替え・問題の図・検索・問題セット・アカウント同期・学習記録の保全・自動テスト）。
旧名は Mathel（v0.2 まで）。学習記録の保存名 `euclea.v1` と問題ID は v0.2 から変わらないので、同じ URL ならそのまま続きから使えます。

**理念**（Lemma と共通）：登録なしで十分に使えること。演習・復習・ヒント・解説は誰でも無料。基礎・標準の少ない問題は周回し、院試レベルの問題は量をこなす。
iPhone・iPad のブラウザで動き、ホーム画面に追加するとアプリとして使えます（PWA）。

## コースと収録範囲

「今日の学習」の上のタブでコースを切り替えます。今日の演習・ランダム・分野ごとの演習・復習・定着度・問題セットは、選んだコースの中で行います（学習記録はコースをまたいで共通）。

| コース | 分野 |
|---|---|
| 大学数学・解析 | 微分積分学／多変数解析／実解析／複素解析／常微分方程式／関数解析／偏微分方程式 |
| 大学数学・代数 | 線形代数／群論／環論／体論／ガロア理論／表現論 |
| 大学数学・幾何 | 集合と位相／線形幾何／位相幾何／微分幾何／リーマン幾何／微分トポロジー |
| 大学数学・その他 | 確率論・統計学／離散数学／数理論理／応用数学 |
| 数学検定1級 | 解析／線形代数／代数・整数論／確率・統計／幾何・複素関数（テーマに【1次】【2次】） |
| 統計検定2級 | データの記述と要約／確率と確率分布／標本分布／推定／仮説検定／回帰分析と相関／標本調査と実験計画 |
| 統計検定準1級 | 確率と確率分布／推定と検定／回帰分析と線形モデル／多変量解析／時系列解析／ベイズ統計と計算統計 |
| 統計検定1級 | 確率分布と極限定理／点推定と十分統計量／区間推定と仮説検定／線形モデルと多変量解析／統計応用 |

収録数は 805問（大学数学は各分野20問・計460問、検定は各分野15問・計345問）。各分野の単元と問題の対応は [docs/coverage.md](docs/coverage.md)。

**難易度**：大学数学は 0=基礎（意欲的な高校生でも解ける）・1=標準・2=演習・3=院試・4=院試難関 の5段階。検定は 1=易・2=標準・3=難 の3段階。難易度の選択は大学数学と検定で別に持ちます。

**頻出度**（高・中・低）：院試・検定や他の分野でも繰り返し使われる考え方を扱う問題ほど高い。EUCLEA では、主な解法が問題集全体でどれだけ使われているかから自動で判定します（`tools/make_values.py`。管理表の「頻出度」列に書けばそちらが優先）。

## できること

- **今日の学習**：今日解いた数／目標、中断した演習の「前回の続き」、復習待ち・要復習の解法・まだ学んでいない解法・解法を違う文脈で使う問題・苦手分野・新しい問題を、理由つきで選ぶ「今日の演習を始める」。解答後は「類題を1問追加」
- **ランダム・分野ごとに演習・複数の分野を組み合わせる・復習だけ**（コースの中で）
- **解法カード**（`content/techniques.json`、250枚）：大学数学・検定の解法・技法・定理の使い方ごとに、概要・核心・使う場面・着眼点・注意点、前提・発展・別のアプローチをまとめたカード。全問が管理表の「解法」列でカードに結びつき（先頭が主な解法）、解法ごとに未学習・学習中・要復習・習得を判定する。詳しくは `docs/techniques.md`。カードの説明はまだ人の確認を受けていない（画面に表示）
- **段階ヒント・自信度・答えを入力して自動採点**（範囲・順不同の組・場合分け・`≈` 付きの近似値・指数表記・添字やギリシャ文字の変数）。証明・説明の小問は「記述：要点」で、答え合わせのときに証明の骨子を見せて自己採点
- **解答の形式**：設定で 記述式（入力）・選択式（4択）・自己採点 を切り替え
- **計算トレーニング**：行列と固有値・留数計算・確率統計の計算・特殊な積分・ベクトル解析・近似と展開・微分・積分
- **グラフ電卓**（2D・3D・複素数平面・ベクトル）と問題の図
- **定着度**：コースごとのレーダー図（大学数学は科目、検定は分野）と分野の色分け、自信と結果のズレ、次にやること
- **検索・問題セット・ブックマーク**（`#set=` `#ids=` `#search=` のリンクで共有）
- **亀のゼノ**（ゼノンの「アキレスと亀」から）：休憩や体調を気づかう声かけ、勉強のアドバイス、数学者の名言
- **アカウントと同期**：メールに届くコードでログインすると、学習記録を複数の端末で使え、サーバーにも保存される（下記）。ログインしなければ端末の中だけ
- ライト／ダーク、効果音、オフライン動作、学習記録の書き出し・読み込み（形を確かめてから合わせるか置き換えるかを選ぶ）

## 問題管理表から問題を取り込む

問題は `EUCLEA問題管理表.xlsx`（問題一覧シート）で管理し、正規データ `content/` とアプリ用データ `data/` に変換します（形式は [docs/data-spec.md](docs/data-spec.md)。Lemma と同じ）。

```sh
pip3 install openpyxl jsonschema sympy antlr4-python3-runtime==4.11
python3 tools/import_xlsx.py EUCLEA問題管理表.xlsx     # content/ と data/ を作り直す（選択肢・図・頻出度も）
node tests/run.mjs                                    # 検査（全部 ✓ になればOK）
```

- **管理表（xlsx）はリポジトリに入れない**（Lemma と同じ運用。`.gitignore` 済み）。手元に日付つきで保存しておく
- 問題ID・分野ID（`AN-01` など。`content/taxonomy.json` で固定）は変えない・消さない（`tests/golden/ids.txt` と照合）
- 「解法」列：解法カードの ID か名前を読点区切り（先頭が主な解法）。全問に書く
- 「入力用の答え」列の書き方・問題の作り方は [docs/problem-guide.md](docs/problem-guide.md)。新しい問題は `python3 tools/validate_new.py 新しい問題.json` で検査してから管理表に入れる
- 自動の図が意味をなさない問題は `content/figures-skip.json` に ID を書く（手で図を付けるときは管理表の「図の式」列）
- 問題セット：`content/collections/` に JSON を置いて `python3 tools/build_app_data.py`
- タグの言い換え：`content/tags.json` の `aliases`

## アカウントと同期（Supabase）

Lemma と同じ Supabase プロジェクトを使います（同じメールアドレスなら同じアカウント。記録は EUCLEA 専用の表 `euclea_state` に分けて保存）。

1. Supabase の SQL Editor で `supabase/schema.sql` を1回実行する（表 `euclea_state` と退会用の関数）
2. 続けて `supabase/guard.sql` を実行する（サーバー側で記録の消失・巻き戻しを断る。何度実行してもよい）
3. 接続先は `js/config.js`（Lemma と同じ Project URL と Publishable key）。空にすると同期の機能は出ない
4. 認証メールの文面はプロジェクトで1つなので、サービス名を出さない共通の文面（「学習アプリ共通アカウントのログインコード」など）にしておく

退会すると、共通アカウントなので Lemma の記録も消えます（プライバシーポリシーに記載）。EUCLEA の記録だけ消すときは「記録をすべて消す」。

## 公開する

**GitHub Pages**（今の公開方法）：Settings → Pages → Branch を `main` / `/ (root)`。`https://kurowasan3.github.io/EUCLEA/` で開けます。リポジトリ全体（`content/`・`tools/`・`tests/` も）が配信される点に注意。

**Cloudflare Pages**（Lemma と同じ方法。リポジトリを非公開にするとき）：`python3 tools/build_dist.py` で必要なファイルだけの `dist/` を作り、`.github/workflows/ci.yml` が main への push のたびに検査して配置します（Settings → Secrets and variables → Actions に `CF_PAGES_PROJECT`・`CLOUDFLARE_API_TOKEN`・`CLOUDFLARE_ACCOUNT_ID` を登録。未登録の間は検査だけ）。

更新したときは `sw.js` の `VERSION` を上げると、端末のキャッシュも入れ替わります。URL を変えると、ログインしていない人の記録は新しい URL から見えません（設定 →「学習記録のバックアップ」で書き出して、新しい URL で読み込む）。

## 構成

Lemma と同じ（`js/`・`css/`・`content/`・`data/`・`tools/`・`tests/`・`supabase/`）。EUCLEA で変えたところ：

- `js/catalog.js`：コース（`COURSES`）・難易度の名前（大学数学／検定）・コースごとの今日の演習
- `js/app.js`：コースのタブ・難易度ボタン・亀のゼノ・グラフの例
- `js/ui.js`：亀のゼノと数学者の名言、`js/drill.js`：大学数学・統計の計算トレーニング
- `js/answer.js`・`js/parser.js`：`≈` の近似値、指数表記、添字・ギリシャ文字の変数（旧 EUCLEA から）
- `js/content.js`：内蔵問題なし（空）
- `tools/make_values.py`：頻出度の自動判定、`content/figures-skip.json`：自動の図を出さない問題
- `supabase/`：表 `euclea_state`・`euclea_private`（Lemma と同じプロジェクトに足せる名前）

ビルド不要。ローカルでは `python3 -m http.server` を実行して `http://localhost:8000` を開きます。
